## 아기고라파덕 `babypsyduck` (모델링)

고라파덕의 아기 버전 Blockbench 모델입니다. 고라파덕 텍스처 색으로 칠한 기본·이로치·알파 텍스처와 애니메이션 13종, Cobblemon 포저·리졸버가 들어 있습니다.
