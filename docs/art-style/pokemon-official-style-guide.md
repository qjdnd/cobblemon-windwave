# 포켓몬 공식 아트 스타일 분석 가이드 (1~10세대)

이미지 생성 AI로 **공식 일러스트(켄 스기모리 계열 공식 아트워크)와 비슷한 결과**를 얻기 위한 분석 문서입니다.
실제 프롬프트 문장은 [`prompt-templates.md`](./prompt-templates.md)에 따로 정리했습니다.

> 범위: 본가 시리즈 공식 일러스트(흰 배경, 전신, 단독 포켓몬). 애니메이션 캡처·TCG 카드 일러스트·도트 스프라이트는 별개의 스타일이므로 제외합니다.

---

## 0. 한 줄 요약

**"큰 도형 2~3개로 된 실루엣 + 3~4색 면 분할 + 끝이 가늘어지는 진한 외곽선 + 경계가 딱 떨어지는 1단 그림자 + 부드럽게 번지는 하이라이트 + 좌상단 광원 + 순백 배경."**
세대가 바뀌어도 이 뼈대는 그대로이고, 바뀌는 것은 **채색 매체(수채 → 디지털)**, **형태의 둥글기**, **그라데이션 양** 정도입니다.

---

## 1. 전 세대 공통 DNA

### 1-1. 실루엣과 형태 언어
- **실루엣 테스트**: 검게 칠해도 어떤 포켓몬인지 알아볼 수 있어야 합니다("이 포켓몬은 누구일까?" 실루엣). 귀·꼬리·뿔·지느러미 같은 **특징 부위 1~2개가 실루엣 밖으로 확실히 튀어나오게** 합니다.
- **기본 도형 조합**: 몸통은 원·타원·물방울·서양배 모양, 포인트는 삼각형(뿔·귀·불꽃)과 S자 곡선(꼬리)으로 만듭니다. 형태를 자잘하게 쪼개지 않습니다.
- **모티프는 1~2개만**: 실존 생물 하나 + 타입 요소 하나(예: 게코 + 물방울)가 기본이고, 여기에 지방 문화 모티프가 더해지기도 합니다. 3초 안에 "뭘 본떴는지" 읽혀야 합니다.
- **디테일은 적게**: 털은 한 올씩 그리지 않고 3~6개의 큰 **털 뭉치**로 묶습니다. 비늘이나 깃털도 대표 패턴 몇 개로만 표현하고, 표면 텍스처는 거의 넣지 않습니다.

### 1-2. 진화 단계별 비율
| 단계 | 머리 : 몸 | 특징 |
|---|---|---|
| 1단계(기본형·스타터) | 머리가 전신 높이의 40~50% | 큰 머리, 짧은 팔다리, 둥근 형태, 색 2~3개 |
| 2단계 | 머리 약 1/3 | 팔다리가 길어지고 모티프 요소가 커짐 |
| 최종 진화 | 머리 1/4~1/5 | 각이 늘어남, 뿔·갑주·장식이 추가됨, 위풍당당한 자세 |

진화하는 동안에도 **주색과 마킹(무늬)의 위치는 유지**해서 같은 계통으로 보이게 합니다.

### 1-3. 색 설계
- **주색 1 + 보조색 1~2 + 포인트색 1**, 합쳐서 3~4색이 기본입니다. 큰 면으로 나누어 칠합니다(배·얼굴 아래는 밝은 크림색·흰색, 등은 주색인 식).
- 색을 보면 타입이 떠올라야 합니다. 아래는 자주 쓰이는 조합입니다(필수 규칙은 아님).

| 타입 | 자주 쓰는 색 |
|---|---|
| 노말 | 베이지, 크림, 갈색 |
| 불꽃 | 주황·빨강 + 노랑 불꽃 + 크림 배 |
| 물 | 파랑·하늘색 + 크림/흰 배 |
| 풀 | 초록·연두 + 갈색/크림, 꽃 포인트 |
| 전기 | 노랑 + 검정 포인트 |
| 얼음 | 연청록, 흰색, 연보라 |
| 격투 | 갈색, 빨강, 회색 |
| 독 | 보라, 자홍 |
| 땅 | 황토, 갈색 |
| 비행 | 하늘색, 흰색, 회색 |
| 에스퍼 | 분홍, 보라 |
| 벌레 | 연두, 빨강, 노랑 |
| 바위 | 회갈색 |
| 고스트 | 보라, 짙은 남보라 |
| 드래곤 | 파랑·보라·빨강 계열 |
| 악 | 검정, 진회색 + 빨강/노랑 포인트 |
| 강철 | 은회색, 청회색 |
| 페어리 | 분홍, 흰색, 파스텔 |

### 1-4. 선(라인아트)
- **외곽선은 굵게, 내부선은 그 절반 정도로 가늘게** 그립니다.
- 선 끝은 **가늘어지며(테이퍼)** 사라집니다. 기계 같은 디자인에도 손으로 그린 느낌이 남는 이유입니다.
- 선 색은 순검정(#000)보다 **아주 짙은 회갈색이나 남색**에 가까운 경우가 많습니다.
- 선은 깨끗하고 한 번에 그은 선입니다. 스케치처럼 겹친 선이나 해칭은 쓰지 않습니다.

### 1-5. 음영(셰이딩)
- **광원은 하나**이고 대개 **좌상단**에 있습니다. 그래서 그림자는 우하단 쪽, 즉 머리 아래·팔다리 안쪽·배 아래에 생깁니다.
- **그림자는 경계가 또렷한 1단**(셀 셰이딩)입니다. 그림자 위에 그림자를 겹치지 않으며, 깊은 틈에만 짧은 2단을 넣습니다.
- **하이라이트는 부드럽게 번집니다**. 둥근 부위의 좌상단에 타원형 광이 은은하게 퍼집니다. "그림자는 딱딱하게, 빛은 부드럽게"가 이 스타일의 핵심 비대칭입니다.
- **그림자는 색상을 이동시킵니다(hue shift)**. 같은 색을 어둡게만 만들지 않습니다.
  - 따뜻한 색(노랑·주황)의 그림자 → 주황·적갈색 쪽
  - 차가운 색(파랑·초록)의 그림자 → 남색·보라 쪽
  - 대략 명도 −20~30%, 채도 약간 올림, 색상 10~20° 회전
- 반짝이는 부위(눈, 보석, 등껍질, 금속)에만 **작고 흰 정반사 점**을 찍습니다.

### 1-6. 눈과 표정
- 눈은 단순한 형태입니다(타원 + 동공 + 흰 하이라이트 1개). 애니메이션식 큰 반짝이 눈이나 여러 겹 하이라이트는 공식 일러스트와 다릅니다.
- 1세대에서 최근 세대로 갈수록 눈이 커지고 둥글어집니다(귀여운 쪽으로 이동).

### 1-7. 구도와 배경
- **전신, 단독, 3/4 시점**(약간 정면 쪽으로 튼 측면)이 기본입니다.
- 특징 부위(꼬리 끝, 등 무늬 등)가 모두 보이는 자세를 고릅니다. 가려지는 부위가 없게 합니다.
- **순백 배경**에 바닥 그림자, 소품, 텍스트, 테두리가 없습니다.
- 동세는 정적인 자세에서 중간 정도까지이고, 액션 이펙트는 거의 넣지 않습니다(불꽃·물 같은 몸의 일부는 예외).

## 2. 세대별 분석

각 세대 끝의 **스타일 키워드**는 프롬프트에 그대로 붙일 수 있는 영어 수식어입니다(→ `prompt-templates.md`의 세대 수식어 표).

### 1세대 — 레드·그린·블루 / 피카츄 (1996, 관동)
- **매체**: 손으로 그린 수채 + 잉크. 종이 질감과 투명한 겹칠이 보이고, 하이라이트는 종이의 흰색을 남겨서 표현합니다.
- **선**: 굵기가 고르지 않고 다소 거칩니다. 손맛이 강합니다.
- **형태**: 이후 세대보다 **"몬스터"스럽습니다**. 파충류 같은 특징, 각진 실루엣, 다소 어색한 해부 구조, 뻣뻣한 자세(옆모습·정면 위주)가 많습니다.
- **색**: 채도가 낮고 바랜 듯한 톤입니다. 그림자가 얕습니다.
- **스타일 키워드**: `1996 traditional watercolor and ink illustration, slightly rough uneven ink lines, light translucent washes, paper white highlights, muted desaturated palette, stiff pose, monster-like proportions`

### 2세대 — 금·은 / 크리스탈 (1999, 성도)
- **매체**: 수채를 유지하되 더 정돈되었습니다. 선이 깨끗해지고 굵기가 고르게 됩니다.
- **형태**: **둥글고 귀여운 쪽**으로 이동합니다. 베이비 포켓몬이 처음 나온 세대라 귀여움이 강조되고, 일본 전통 모티프가 늘었습니다.
- **색**: 1세대보다 밝고 맑으며, 부드러운 수채 번짐이 있습니다.
- **스타일 키워드**: `late-1990s watercolor illustration, cleaner even ink lines, softer rounder shapes, gentle wash shading, bright clear palette`

### 3세대 — 루비·사파이어 / 에메랄드 (2002, 호연)
- **매체**: 이 무렵부터 **디지털 채색 느낌이 뚜렷**해집니다. 수채 느낌을 흉내 낸 매끈한 채색입니다. 스기모리가 이 세대 신규 포켓몬의 홍보용 일러스트를 모두 직접 그렸습니다.
- **선**: 굵고 명확한 외곽선
- **음영**: 그림자 경계가 더 또렷해지고, 하이라이트가 강해져 **광택감**이 생깁니다.
- **형태**: 볼륨감이 늘고, 근육·덩어리 표현이 늘며, 자세가 더 역동적입니다.
- **색**: 채도가 높고 대비가 강합니다.
- **스타일 키워드**: `early-2000s digital painting with watercolor feel, bold clean outlines, stronger contrast, glossy soft highlights, saturated colors, dynamic pose`

### 4세대 — 다이아몬드·펄 / 플라티나 (2006, 신오)
- **매체**: 완전한 디지털 **셀 셰이딩**입니다.
- **선**: 가늘고 일정하며 깔끔합니다.
- **음영**: 하드엣지 그림자 1단 + 그라데이션 하이라이트. 오늘날 "공식 일러스트 느낌"의 기준이 되는 렌더링이 여기서 굳어집니다.
- **형태**: 조형적·기하학적입니다. 전설 포켓몬은 갑옷이나 기계 같은 장식이 붙은 거대한 형태이고, 기존 포켓몬의 진화형이 많이 추가되었습니다.
- **색**: 조금 차분하고 회색기가 돕니다. 금속·보석 포인트가 있습니다.
- **스타일 키워드**: `mid-2000s clean digital cel shading, thin even linework, geometric sculpted forms, slightly muted palette, metallic accents`

### 5세대 — 블랙·화이트 / BW2 (2010, 하나 — 뉴욕 모티프)
- **형태**: **각지고 그래픽한** 디자인이 많습니다. 줄무늬·기하 패턴으로 면을 나누고, 도시·산업 모티프가 쓰입니다.
- **음영**: 4세대보다 정돈된 셀 음영입니다. 색 면의 경계가 칼같이 나뉘고 대비가 강합니다.
- **스타일 키워드**: `crisp graphic shapes, bold color blocking, angular silhouettes, sharp clean cel shadows, high contrast`

### 6세대 — X·Y (2013, 칼로스 — 프랑스 모티프)
- 본가 시리즈에서 처음으로 **3D 모델을 전제로 디자인**했습니다. 디자인을 단순한 입체 도형으로 구성했기 때문에 콘셉트 아트 단계부터 입체감이 강합니다. 3D 모델 제작 일정상 디자인도 일찍 확정했습니다.
- **음영**: 부드러운 그라데이션이 늘어 볼륨감이 커지고 매끈하게 다듬어진 렌더링입니다.
- **메가진화**: 가시·장식·색 반전·비대칭으로 형태를 과장합니다.
- **스타일 키워드**: `smooth volumetric cel shading, simple primitive 3D-friendly forms, polished clean rendering, vivid colors`

### 7세대 — 썬·문 / 울트라썬·울트라문 (2016, 알로라 — 하와이 모티프)
- **10세대와 가장 가까운 참고 세대입니다**(열대 섬 지방).
- **색**: 밝고 채도가 높은 **열대 팔레트**에 따뜻한 햇빛 느낌입니다.
- **형태**: 장난스럽고 둥근 형태가 많습니다. 리전폼(알로라의 모습)이 처음 나왔고, 기존 종을 지역 환경에 맞게 재해석했습니다.
- **예외**: 울트라비스트는 일부러 이질적·추상적인 디자인입니다(일반 포켓몬 생성에는 참고하지 않음).
- **스타일 키워드**: `bright tropical palette, warm sunlight feel, clean soft cel shading, playful rounded shapes`

### 8세대 — 소드·실드 (2019, 가라르 — 영국 모티프)
- **렌더링**: 7세대 방식을 유지하면서 색 면 분리를 더 정돈해 조금 더 플랫해졌습니다.
- **다이맥스/거다이맥스**: 거대화하고, 구름·에너지 효과로 연출합니다(일반 일러스트와는 다른 특수 연출).
- **스타일 키워드**: `polished modern cel shading, clean color separation, slightly flat rendering`

### 9세대 — 스칼렛·바이올렛 (2022, 팔데아 — 이베리아 모티프) + 레전드 시리즈
- **렌더링**: 셀 그림자 면 안에 **부드러운 에어브러시 그라데이션**이 들어가고, 반사광(외곽의 은은한 림 라이트)이 보이며, 재질감이 약간 더 생겼습니다. 역대 가장 "그려 놓은" 느낌이 강합니다.
- **디자인**: 패러독스 포켓몬(고대 = 야생·원시, 미래 = 금속·사이버), 테라스탈(보석 결정 왕관)이 있습니다. 여러 사내 디자이너가 디자인에 참여했고, 공식 일러스트로 통일해서 마무리합니다.
- **레전드 아르세우스(2022, 히스이)**: 옛 일본(신오의 과거) 모티프의 리전폼이 나옵니다. 나무·전통 문양·거친 야생성이 특징입니다.
- **레전드 Z-A(2025)**: 새 메가진화가 다수 추가되었습니다.
- **스타일 키워드**: `contemporary official artwork, cel-shaded forms with soft airbrushed gradients, subtle rim light, refined but restrained detail`

### 10세대 — 윈즈·웨이브즈 (2027년 예정, Nintendo Switch 2)
**이 프로젝트(Cobblemon Wind Wave)의 기준 세대입니다.**

- **확정 정보(2026년 2월 27일 Pokémon Presents 기준)**: 동남아시아에서 영감을 받은 **열대 군도** 지방이고, 지방 이름은 아직 발표되지 않았습니다. 바다·해변·정글·화산·습지·물 위의 풍차 구조물이 나오며 수중 탐험이 있습니다.
- **스타터 3종**(최신 공식 스타일의 기준점):
  - **Browt** – 풀 타입, "콩병아리 포켓몬(Bean Chick Pokémon)". 병아리와 **싹 튼 콩**을 합친 초록색 새입니다.
  - **Pombon** – 불꽃 타입, "강아지 포켓몬(Puppy Pokémon)". **주황색 복슬복슬한 포메라니안** 강아지입니다. 목 아래가 폐 속 열 기관 때문에 은은하게 빛납니다.
  - **Gecqua** – 물 타입, "물게코 포켓몬(Water Gecko Pokémon)". 파란 **게코 도마뱀**(납작꼬리게코·볏도마뱀붙이 계열)으로, 몸에 비해 머리와 눈이 큽니다. 반쯤 감긴 눈에 속눈썹 같은 돌기가 있고, 눈꺼풀과 세 발가락 끝은 청록색입니다. 배·등줄무늬·꼬리와 이마의 **물방울 마킹**은 옅은 하늘색이고, 짧고 뭉툭한 꼬리로 물방울 공을 튕겨 쏩니다.
  - 이 문서는 영어 이름으로 표기합니다. 한국어 공식 이름은 확인한 뒤 덧붙이세요.
- **스타터에서 읽히는 디자인 경향**: 아주 둥글고 **인형으로 만들기 좋은** 형태, 큰 머리, 단순한 색 블록, 표정 중심의 매력입니다. 1세대의 "몬스터" 성향에서 가장 멀리 온 상태입니다.

## 4. 이미지 생성 AI에서 자주 생기는 실패와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 털이 한 올씩 그려져 사실적으로 나옴 | 디테일 억제가 없음 | `simplified clumped fur shapes, minimal surface detail` + 부정 프롬프트 `fur strands, realistic texture` |
| 애니메이션 캡처처럼 나옴 | `anime` 키워드 | `anime`을 빼고 `official character artwork, key illustration` 사용 |
| 기존 포켓몬(피카츄 등)이 섞임 | `Pokémon`이라는 단어가 기존 캐릭터 쪽으로 끌어당김 | 모티프를 구체적으로 묘사하고 `original creature design, not an existing species` 추가. 필요하면 `Pokémon`을 빼고 `monster-collecting RPG official artwork` 사용 |
| 3D 렌더·플라스틱처럼 나옴 | 9세대 키워드의 그라데이션 과다 | `2D illustration, hand-drawn line art, visible outlines` 추가, `3D render, CGI`를 부정 프롬프트에 |
| 배경·바닥이 생김 | 배경 지정 없음 | `isolated on pure white background, no ground shadow` |
| 색이 너무 많아짐 | 팔레트 미지정 | 색을 3~4개로 명시(가능하면 HEX 값) |
| 눈이 모에화되어 거대해짐 | 애니·치비 편향 | `simple small eyes with single highlight`, 부정 프롬프트 `chibi, sparkly anime eyes` |
| 외곽선이 없어짐 | 페인터리 편향 | `clean bold dark outlines, tapered line weight` |
| 그림자가 여러 겹 | 렌더링 편향 | `one hard-edged shadow tone, soft diffused highlights` |
| 진화 단계끼리 안 닮음 | 각각 따로 생성 | 진화 라인을 한 장에 같이 생성하거나, 앞 단계 이미지를 참조 이미지로 넣기 |

## 5. 완성본 검수 체크리스트

- [ ] 검게 칠해도 실루엣으로 알아볼 수 있는가
- [ ] 모티프(생물 + 타입)가 3초 안에 읽히는가
- [ ] 주요 색이 4개 이하이고 타입을 연상시키는가
- [ ] 외곽선이 내부선보다 굵고, 선 끝이 가늘어지는가
- [ ] 광원이 하나(좌상단)이고 그림자가 1단 하드엣지인가
- [ ] 그림자가 색상 이동(따뜻한 색 → 적갈, 차가운 색 → 남보라)되어 있는가
- [ ] 털·비늘이 단순한 덩어리로 정리되어 있는가
- [ ] 전신, 3/4 시점, 특징 부위가 모두 보이는가
- [ ] 순백 배경에 소품·텍스트·바닥 그림자가 없는가
- [ ] 진화 라인이라면 주색·마킹 위치가 이어지는가
- [ ] 기존 공식 포켓몬과 지나치게 닮지 않았는가

## 6. Cobblemon 작업에서 쓰는 법

생성 이미지는 **최종 텍스처가 아니라 디자인 기준 자료**로 씁니다.

1. **콘셉트 확정**: 공식 일러스트 템플릿으로 여러 장 뽑고, 체크리스트로 1장을 고릅니다.
2. **턴어라운드 시트**: 고른 디자인으로 정면·측면·후면·3/4 시트를 생성해서 Blockbench 모델링의 기준으로 씁니다(템플릿 D).
3. **팔레트 추출**: 고른 일러스트에서 기본색·그림자색·하이라이트색 HEX를 뽑아 텍스처에 씁니다. 공식 3D 모델처럼 텍스처에는 **큰 색 면 + 약한 음영**만 넣고, 강한 음영은 게임 조명에 맡깁니다.
4. **이로치(색이 다른 포켓몬)**: 같은 형태에서 주색만 바꾼 변형을 템플릿 F로 뽑아 비교합니다.

> 포켓몬 IP의 권리는 Nintendo / Creatures / GAME FREAK / The Pokémon Company에 있습니다. 공식 일러스트를 그대로 베끼기보다 이 가이드의 원칙으로 **새로 디자인**하는 쪽이 결과물의 질에도, 팬 프로젝트로서의 안전에도 좋습니다.
