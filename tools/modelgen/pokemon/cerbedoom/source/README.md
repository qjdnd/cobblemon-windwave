# Source: Cobblemon's Houndoom

Unmodified copies of Cobblemon 1.8.1's Houndoom files, used as the source of Cerbedoom's texture:

| File | From (cable-mc/cobblemon, tag 1.8.1, `common/src/main/resources/assets/cobblemon/`) |
|---|---|
| `houndoom.png` | `textures/pokemon/0229_houndoom/houndoom.png` |
| `houndoom_shiny.png` | `textures/pokemon/0229_houndoom/houndoom_shiny.png` |
| `houndoom_male.geo.json` | `bedrock/pokemon/models/0229_houndoom/houndoom_male.geo.json` (reference for proportions only) |
| `LICENSE` | the repository's `LICENSE` (Mozilla Public License 2.0) |

The Houndoom folder in Cobblemon has no separate asset license, so these files fall under the
repository's Mozilla Public License 2.0 (see `LICENSE`). Cerbedoom's texture is built from them: its
fur, orange and bone texels are copied 1:1 from pure fur / orange / bone areas of `houndoom.png` and
kept on Houndoom's own colour ramps; the shiny uses the matching colours of `houndoom_shiny.png`.
Cerbedoom's model, eyes and animations are new.
