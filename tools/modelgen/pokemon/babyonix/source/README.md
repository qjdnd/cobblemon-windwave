# Source: Cobblemon's Onix

Unmodified copies of Cobblemon 1.8.1's Onix files, used as the source of Baby Onix's rock texture:

| File | From (cable-mc/cobblemon, tag 1.8.1, `common/src/main/resources/assets/cobblemon/`) |
|---|---|
| `onix.png` | `textures/pokemon/0095_onix/onix.png` |
| `onix_shiny.png` | `textures/pokemon/0095_onix/onix_shiny.png` |
| `onix.geo.json` | `bedrock/pokemon/models/0095_onix/onix.geo.json` (only used to find the boulder faces in the texture) |
| `LICENSE` | `bedrock/pokemon/models/0095_onix/license` |

The Onix model and texture are by the Cobblemon team and licensed under Creative Commons
Attribution-NonCommercial 3.0 (see `LICENSE`). Baby Onix's texture is an adaptation: the rock
pattern is cut from Onix's boulder faces and re-shaded; Baby Onix's model, eyes and animations are new.
